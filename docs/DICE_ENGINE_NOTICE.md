# Physical 3D Dice Engine

The integrated dice runtime is derived from the supplied dice-main package and uses Three.js, Cannon.js, and teal.js. The supplied dice-main license is MIT. The runtime supports d4, d6, d8, d10, d12, d20, and d100 with physical animation and audio.

No Dice Bot code, bot personalities, bot response banks, or bot token assets are included in this build.
