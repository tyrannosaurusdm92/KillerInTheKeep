# Art and Asset Notice

## Original project artwork

The character portraits, title artwork, board reference, card illustrations, room art, trap art, monster art, weapon art, and related supplied visual material originated in the user-provided Killer In The Keep project. The user stated that a friend created this art and asked that its appearance remain relatively unchanged.

That artwork is preserved for this project and is **not relicensed by the GPL code license**. No ownership transfer is asserted. Redistribution, commercial use, sublicensing, model training, or use outside Killer In The Keep requires permission from the applicable artist/rightsholder unless another written license already governs the specific asset.

## New map presentation

The supplied Murderkeep map-design material was used to build four digital map concepts and SVG blueprints. The latest user instruction controls the product name: the game remains **Killer In The Keep** even where historical source material used another working title.

Each shipped raster map is presented on a 48 × 32 grid. The game overlays the authoritative 5-foot cell grid at runtime.

## Character sheets

The eight supplied HTML character sheets were used as the source for character facts and embedded portrait images. They were consolidated into JSON and image assets so the finished package retains exactly one HTML entry file.

## Prohibited external game assets

No copyrighted assets from the commercial game associated with Pal3.Unity are included. The repository itself separates code from original game assets, and this package uses only independently implemented browser patterns.
