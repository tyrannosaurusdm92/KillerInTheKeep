# Licenses and Attribution Index

The in-game Licenses tab opens the actual included files listed below.

- `licenses/NOTICE_SRD_5.2.1.md` — SRD attribution and independence notice.
- `licenses/CC-BY-4.0.txt` — Creative Commons Attribution 4.0 International legal code.
- `licenses/PROJECT_LICENSE.md` — original-project license status.
- `licenses/THIRD_PARTY_SOFTWARE.md` — bundled runtime software notices.
- `licenses/ASSET_LICENSES.md` — map, art, token, and card provenance.
- `licenses/AUDIO_LICENSES.md` — original procedural audio provenance.
- `licenses/FONT_LICENSES.md` — font record; no font binaries are bundled.
- `EXTERNAL_RESEARCH_AND_LICENSE_AUDIT.md` — evaluated sources and exclusion decisions.
- `source-manifests/` — retained provenance records from supplied packages.

No public URL, shared Drive status, or GitHub visibility was treated as proof of redistribution rights. Unverified Drive/repository assets were not imported.
