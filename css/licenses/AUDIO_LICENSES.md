# Audio Licenses and Provenance

The v6.1.0 production audio set contains seven quiet WAV files:

- `dice_character_quiet.wav`
- `dice_monster_quiet.wav`
- `door_open_quiet.wav`
- `lock_quiet.wav`
- `trap_quiet.wav`
- `fireplace_loop_quiet.wav`
- `keep_ambience_loop_quiet.wav`

These files were procedurally synthesized specifically for this merge. They do not contain sampled commercial recordings or newly imported third-party audio. The obsolete selectable dice-sound set and longer roll audio were removed from the production build.

The two dice sounds are fixed by role: one shared character/character-bot sound and one shared monster sound. No player-facing sound customization is exposed.


## Version 6.1 dynamic effect audio

All files in `assets/audio/effects/` were procedurally synthesized specifically for this package. They contain no sampled third-party recordings. Cues cover character spellcasting, weapon impacts, monster movement and attacks, poison/healing states, perception/detection, and death events.
