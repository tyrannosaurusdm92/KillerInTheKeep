# Font License Record

No font files are bundled in this production package. The interface and generated SVG assets use browser/system font-family fallbacks such as `system-ui`, `sans-serif`, and `Georgia`.

Because no redistributable font binary is included, there is no separate third-party font license to ship. A future build that bundles a webfont must add the font file, source, license text, attribution requirements, and file hash to this record and the package manifest.
