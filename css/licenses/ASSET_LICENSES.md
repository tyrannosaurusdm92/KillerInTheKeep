# Asset Licenses and Provenance

## User-supplied project assets

The four SVG maps, character artwork, character sheets, original card decks, interface artwork, and other game-specific assets came from the supplied project package. They remain governed by the project owner's rights and any source-specific notices retained in this documentation tree.

Relevant retained records include:

- `CHARACTER_ART_LICENSE.json`
- `MAP_CONVERTED_ASSETS_LICENSE.json`
- `../source-manifests/ART_SOURCE_MANIFEST.json`
- `../source-manifests/MAP_SOURCE_INTEGRATION_MANIFEST.json`

## New merge assets

The eight bordered character token wrappers use the supplied character art. The Mimic and Gelatinous Cube token/card illustrations added in v6.1.0 are original SVG constructions created for this package and do not copy an external token repository.

## Google Drive source folder

The linked Drive folder was inventoried, but its public/shared status did not establish redistribution rights. No asset from that folder was newly imported into v6.1.0 without an already-retained project source/license record. Large Dungeondraft packs, examples, and unverified source folders were deliberately excluded.

## External token repositories

No external monster, item, treasure, or environmental token repository was imported. Public availability or a GitHub/Drive URL was not treated as proof of a compatible license.
