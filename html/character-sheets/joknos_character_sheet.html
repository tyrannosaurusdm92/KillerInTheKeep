Character Overview

✦

Players use five total Game Levels. Each Game Level immediately applies its D&D-equivalent destination package: 1 = D&D 5, 2 = D&D 9, 3 = D&D 13, 4 = D&D 17, and 5 = D&D 20. Intermediate D&D levels are not processed separately.

Programmed Abilities

✦

Locked cards become active at their required Game Level. D&D-equivalent statistics jump directly to levels 5, 9, 13, 17, and 20. Limited powers have uses equal to the current Game Level.

Five Game Level Packages & Choices

✦

The current Game Level package is highlighted with its D&D equivalent. Only destination-package choices are prompted; skipped D&D levels are never processed one at a time.
